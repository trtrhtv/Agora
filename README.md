# אגורה (agora)

ספרייה אישית של רעיונות לגיבוש תפיסת עולם. האפיון המלא: [SPEC.md](SPEC.md). כללי העבודה: [CLAUDE.md](CLAUDE.md).

## הרצה

```sh
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה; נכשלת על כל קובץ תוכן לא תקין
npm test         # בנייה + בדיקה שקבצים לא תקינים מפילים את הבנייה
```

## מבנה

- `content/` כרטיסי תוכן (Markdown + YAML), תיקייה לכל סוג ישות.
- `src/content.config.ts` סכמות Zod לכל סוג (SPEC סעיף 4).
- `src/lib/integrity.ts` בדיקות בין קבצים: קישורים לפי `id`, מקורות `[^sN]`, התאמת `id` לשם הקובץ.
- `tests/invalid/` קבצים לא תקינים שחייבים להפיל את הבנייה.

## סטטוס

שלב 0 (תשתית) הושלם. שלב 1: מנה ראשונה (מיל, הובס, לוק, ושתי שאלות) מנה שנייה (פרודון, רוסו, קאנט, אפלטון, אריסטו, ועדכון שאלת הלגיטימיות) ומנה שלישית (מקיאוולי, ברק, סמית', מרקס, ניטשה, ועדכון פרודון) ממתינות לבדיקה (🟡 ✋). שאר כרטיסי הדוגמה הם עדיין שלדים לא מאומתים (⚪ ✋).

**שלב 1.5 (מסך קריאה מינימלי):** בנוי. `npm run dev` ופתיחת http://localhost:4321 מציגים רשימת הוגים ושאלות, עמוד לכל כרטיס עם הפניות למקורות, ציטוטים, תג אימות ו"מה לבדוק בכרטיס הזה". השלב הבא לפי SPEC (גרסה 0.3): שבוע של קריאה במסך, ואז קיצור הכרטיסים וסעיף "קרא את זה" על שלושה כרטיסים.
