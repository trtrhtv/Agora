# אגורה (agora)

ספרייה אישית של רעיונות לגיבוש תפיסת עולם. האפיון המלא: [SPEC.md](SPEC.md). כללי העבודה: [CLAUDE.md](CLAUDE.md).

## הרצה

```sh
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה; נכשלת על כל קובץ תוכן לא תקין
npm test         # בנייה + בדיקה שקבצים לא תקינים מפילים את הבנייה
```

## מבנה

- `content/` כרטיסי תוכן (Markdown + YAML), תיקייה לכל סוג ישות.
- `src/content.config.ts` סכמות Zod לכל סוג (SPEC סעיף 4).
- `src/lib/integrity.ts` בדיקות בין קבצים: קישורים לפי `id`, מקורות `[^sN]`, התאמת `id` לשם הקובץ.
- `tests/invalid/` קבצים לא תקינים שחייבים להפיל את הבנייה.

## סטטוס

שלב 0 (תשתית) הושלם. שלב 1, מנה ראשונה (בדיקת פורמט), ממתינה לבדיקה: ההוגים מיל, הובס ולוק, והשאלות "לגיטימיות המדינה" ו"גבולות החירות" (🟡 ✋). שאר כרטיסי הדוגמה הם עדיין שלדים לא מאומתים (⚪ ✋).
